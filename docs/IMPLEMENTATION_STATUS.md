### Hotfix: локальный черновик / выпуск / PDF ✅

**Причины (подтверждены кодом):**
1. **Конфликт ревизий:** `exportDraftDocument` вызывал `issueEstimateVersion`, создавал версию и **увеличивал `draftRevision`**. Повторный «Выпустить версию» со старой ревизией → Conflict. Сообщение UI ошибочно говорило про «другую вкладку».
2. **PDF:** тот же путь — скрытый выпуск версии; при сбое/гонке — конфликт; без отдельного снимка черновика.
3. **Локальный черновик:** на `/draft` не было основной кнопки переноса в редактор (только «Войти» в шапке) → тупик.

**Исправлено:**
- Предварительный PDF строит снимок черновика **без** `EstimateVersion` и **без** bump ревизии
- Выпуск: проверка ревизии в транзакции; идемпотентность по ключу; корректный `draftRevision` в ответе; текст конфликта без «другой вкладки»
- `/draft`: CTA «Войти и продолжить» / «Продолжить в редакторе», qty, единицы «шт.», пустые CTAs
- Клиент держит актуальный `revision` после сохранений

**Проверено:** Vitest (draft-export-no-version, versions, exports); typecheck; lint; e2e CTA; staging после деплоя.
